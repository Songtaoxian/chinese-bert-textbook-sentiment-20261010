# 中文 BERT 教材情感分析初步实验

本机训练的中文情感实验，基础模型为 `google-bert/bert-base-chinese`。

**独立正负测试集准确率 80%，两类 Macro-F1 约 0.800。这不是教材三分类准确率。** 中性训练标签由教材客观陈述的筛选规则生成，尚未人工核验。

## 下载并运行

仓库包含代码、实际数据分区、指标、来源记录和小红书素材。大模型权重位于同一私人仓库的 Releases：下载 `chinese-bert-textbook-sentiment-full.zip` 并解压，即得到带权重的完整项目。

在完整项目目录运行：

```powershell
python main.py --text "导数表示函数相对于变量的瞬时变化率。"
```

也可以双击 `启动中文分析.bat`。直接克隆源码不会带模型权重，请先下载 Release 完整包。

## 实验数据

- 教材：GitHub《动手学深度学习》的线性代数、微积分和概率章节。
- 教材段落共 127 段，102 段参与 60 次 MLM 参数更新，25 段留出试分析。
- NLPCC2014 正负数据共选取 2800 条：2000 条训练、400 条验证、400 条测试。
- 121 条教材中性弱标签句重复采样到 1000 条记录。
- 情感分类实际有 2121 条不同文本，训练文件共 3000 条记录，训练三轮。
- 按验证损失保存第 1 轮模型，随后只在独立测试集上评估一次。

## 成果与限制

400 条正负测试样本准确率 80%，负面 F1 0.803，正面 F1 0.797。
25 个留出教材段落均预测为中性，但没有人工标签，不能计算教材准确率。
正负样本来自微博，中性来自教材，模型可能利用领域差别进行分类。没有真实中性测试标签，也没有有无教材 MLM 的对照，不能声称三分类已验证或教材适应改善了效果。
