# 中文 BERT 教材情感初步训练实验

训练设备：NVIDIA GeForce RTX 5060 Laptop GPU（8GB），本机 CUDA。
基础模型：google-bert/bert-base-chinese。

## 数据与训练

教材：GitHub d2l-ai/d2l-zh《动手学深度学习》的线性代数、微积分、概率章节。
先对 102 个训练段落进行 60 次掩码语言模型参数更新（MLM）。
分类训练：NLPCC2014 中 1000 条负面和 1000 条正面文本，另从教材挑选 121 条弱标注中性句，重复采样到 1000 条；共 3000 条训练记录。
中性标签来自启发式筛选，不是人工金标准。教材句段清理删除了代码和公式，不能用于验证数学理解能力。
训练参数：3 轮，batch=8，最长128 token，AdamW，学习率2e-5，CUDA bf16。
验证集：400 条独立正负样本，用于按验证损失选择模型。保存第 1 轮。
测试集：另留 400 条独立正负样本，仅在选好模型后评估一次。
文本按规范化后精确去重，冲突标签剔除；尚未全面排查近似重复。

## 独立正负测试集结果

- 准确率：80.00%
- 已标注两类 Macro-F1：0.8000
- 负面 F1：0.8030
- 正面 F1：0.7970

混淆矩阵（行=真实类别，列=预测类别，顺序均为负面/中性/正面）：

|真实\预测|负面|中性|正面|
|---|---:|---:|---:|
|负面|163|0|37|
|中性|0|0|0|

测试集没有真实中性样本，因此不能计算或声称中性识别准确率，也不能把上述指标当作三分类或教材准确率。

## 教材试分析

对 25 个未参与 MLM 或分类训练的教材段落预测：{'中性': 25}。
这些段落没有人工标签，结果仅为模型输出，不能视为评估成绩。只分析每段前128 token，过长段落的截断情况见结果文件。
中性弱标签来自教材、正负标签来自微博，模型可能学习到领域差别而非情感；需要人工标注教材三类验证集后确认。
本次没有与未经教材适应的模型做对照，不能声称教材 MLM 提升了效果。
初步模型不等同于已经验证的教材情感分类器。

## 使用

在原项目目录运行：

```powershell
python bert_chinese_sentiment.py predict --model output/github_experiment_v2/sentiment_model --text "导数表示函数相对于变量的瞬时变化率。"
```

或者运行 predict_chinese.ps1。
模型保存在项目 output/github_experiment_v2/sentiment_model；包含训练后的实际模型权重。
原来的 main.py 和 streamlit_app.py 保留英文模型，新中文入口为上述命令。
复现实验脚本：run_github_experiment.py；依赖第一阶段保存的 output/github_experiment_v1/textbook_mlm。
